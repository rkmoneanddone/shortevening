# NashtaBuddy

Lightweight Android-first family evening-snack decision assistant.

## V1 promise
Open app → see 3 ideas → choose → cook → mark Made Today → avoid repeats during the week.

## Commercial model
- 30-day full Premium trial
- Free after trial: 3 basic ideas/day only
- Premium: ₹249/month or ₹1,999/year
- Razorpay
- Firebase backend
- OpenAI/Gemini only through secure backend
